# История изменений

## Не выпущено

## 1.1.0 — 2026-11-16

- Добавлен выбор папки данных скрипта: журналы, временные WAV и MIDI,
  настройки компонентов и локальные окружения больше не привязаны к профилю Windows.
  Обычная установка сохраняет прежнее расположение; портативный REAPER по
  умолчанию использует Data\Ai Transcriber внутри своей папки ресурсов.
- Общая настройка папки в профиле REAPER сохраняется при обновлении и смене
  редакции. Внутренние пути хранятся относительно папки данных и REAPER,
  поэтому установка переносится вместе с ними. Папка моделей выбирается отдельно.
- Сменить папку можно после завершения обработки и загрузок. Данные копируются
  с проверкой SHA-256, исходники остаются на месте; различающиеся файлы назначения
  не перезаписываются. Можно открыть ранее созданную папку без копирования.
  После смены папки скрипт нужно закрыть и открыть снова.
- На дисках с уже обычным уровнем Windows проверка запуска не требует
  повторного изменения метки безопасности. Восстановление пониженных меток
  сохранено; CPU- и Vulkan-движки не пересобирались.
- Проверено на Windows x64: реальные операции копирования, совпадение файлов,
  отказ при занятой папке и различающихся файлах, относительные пути после
  смены расположения REAPER и формат конфигурации движка. Через REAPER MCP
  проверены обе редакции: окно настройки, перенос, переоткрытие и совместная
  настройка папки; CPU и Vulkan подготовили WAV после переноса. Проект не
  изменялся. Полное распознавание и сетевые загрузки в этой проверке не запускались.
  macOS не поддерживается; физический перенос на другой компьютер не проверялся.


## 1.0.4 — 2026-11-15

- Устранена сохранявшаяся в 1.0.3 ошибка AITN-120 при пустом выборе инструментов:
  прямой запуск теперь записывает config.json общим JSON-модулем. Старый
  локальный кодировщик удалён; пустой список сохраняется как массив и включает
  автоматическое определение MuScriptor. Очередь в базовую версию не добавлена.
- Проверка проходит через фактическую функцию одиночной транскрибации и передаёт
  созданный Lua файл обоим движкам без повторного кодирования тестом. Проверены
  автоматический режим, ручной выбор, его сброс и пути с кириллицей.
- Версия, лицензии, манифесты, инструкции и комплект ReaPack согласованы с ZIP.
  Движки не перекомпилировались; модели и пользовательские настройки сохранены.
- В BAT-установку и общий скрытый запуск после ReaPack встроено восстановление
  обычного уровня целостности Windows для папки приложения и обоих движков.
  Унаследованная метка Low больше не приводит к AITN-112. При отказе настройки
  показывается AITN-114 вместо ожидания не запустившегося помощника.
- Убран повтор процентов при загрузке модели и транскрибации.
- Проверки Windows x64: 14 автономных тестов и проверка через REAPER MCP
  на рабочей установке. Подтверждены пустой и ручной выбор, запись прогресса
  обоими движками и однократное отображение процентов; проект не изменялся.
  Полная транскрибация и сетевая установка ReaImGui в тесте не запускались.

## 1.0.3 — 2026-11-15

- Исправлен запуск без выбранных инструментов: пустой список корректно
  включает автоматическое определение MuScriptor вместо ошибки AITN-120.
  Явный выбор одного или нескольких инструментов сохраняет своё поведение.
- Добавлена проверка автоматического режима, ручного выбора и его сброса,
  включая приём параметров CPU- и Vulkan-сборками движка без запуска нейросети.
  Проверки выполнены для Windows x64; полный запуск нейросети, проверка
  в REAPER и сетевая установка ReaImGui не выполнялись.
- Подготовлен согласованный выпуск 1.0.3 для ZIP и ReaPack: обновлены номер,
  лицензии, инструкции и контрольные суммы. Устанавливаемые файлы совпадают;
  движки CPU и Vulkan сохранены без перекомпиляции.

## 1.0.2 — 2026-11-13

- Транскрибация аудио в MIDI прямо в проекте REAPER: выделенные фрагменты
  распознаются локально и ноты появляются на дорожках под исходником. Несколько
  выбранных фрагментов одной дорожки обрабатываются одной партией.
- Два способа установки: ReaPack из общего индекса Aiwist и ZIP с
  BAT-установщиком. Оба ставят одинаковый комплект — Lua-скрипт, CPU- и
  Vulkan-сборки движка, шрифты, лицензии и манифесты.
- Модели Small, Medium и Large устанавливаются из настроек; там же язык,
  устройство вычислений и оформление. Режим «Только CPU» запускает CPU-сборку,
  «Авто» и выбор видеокарты используют Vulkan.
- При первом запуске показываются условия использования и состав лицензий.
  ReaImGui проверяется и при необходимости устанавливается.
- Ограничения: Windows x64, macOS не поддерживается. Сетевая переустановка
  ReaImGui не проверялась; бинарные сборки движка взяты из проверенного комплекта
  без перекомпиляции.
